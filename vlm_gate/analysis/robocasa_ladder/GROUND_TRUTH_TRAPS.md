# robocasa 정답 파일을 쓸 때 조심할 것

이 폴더와 `analysis/robocasa_task_ceilings.json` 을 순위상관 정답으로 쓰기 전에.
(2026-09-16 확인)

## 1. `robocasa_task_ceilings.json` 의 **하한(lo)은 측정값이 아니다**

24태스크 중 19개가 1.5, 5개가 1.0 이다. `analysis/TASK_CEILINGS.md` 에 이렇게
적혀 있다 -- "하한은 **망가지는 태스크가 아니면 1.5 로 고정**한다".

즉 사실상 "망가지나" 이진 표시다. 순위상관 정답으로 쓰면 값이 거의 무의미하다.
**상한(hi)만 측정값이다.**

## 2. 상한과 사다리에는 **태스크 난이도가 섞여 있다**

|  | 1x 성공률과의 rho |
|---|---|
| 천장 hi | **+0.552** |
| 사다리 (`episode_target.parquet` max_ratio 태스크 평균) | **+0.654** |

천장 기준이 "성공률이 허용 폭 안에서 유지된다" 를 요구하고, 1x 성공률 0.35 미만인
태스크는 아예 판정하지 않기 때문이다. 그래서 이 둘로만 재면 "이 순간이 압축
가능한가" 가 아니라 **"이 태스크가 쉬운가"** 를 재고 있을 수 있다.

**1x 성공률을 뺀 순위 부분상관을 같이 내라.**

## 3. 난이도가 약분된 정답은 `nq_noclip.csv` 다

`kN_succ / allfine_succ` 는 자기 1x 로 나눈 값이라 난이도가 약분된다. 1x 성공률과의
rho 가 −0.233 으로, 위 둘과 부호가 반대다.

**K2 는 쓰지 마라 -- 폐루프 포화점이라 거의 모든 태스크가 유지되어 변별력이 없다.**
K3 이 갈린다.

## 4. 1x 성공률 0.35 미만 태스크는 빼고 재라

문서에 있는 규칙인데 지키지 않으면 역전 크기가 실제보다 작게 나온다.

```
                    전체 24태스크   0.35 필터 후 20태스크
현행 가중 vs 사다리      −0.503            −0.693
현행 가중 vs 천장hi      −0.414            −0.641
```

## 5. 세 정답을 같이 내라

하나로 결론 내지 말 것. 그리고 **적합에 쓴 정답과 안 쓴 정답을 구분해서** 보고하라
-- 사다리로만 적합한 가중이 천장 표에서도 +0.376 이면 그건 외삽이 되는 것이고,
사다리에서만 좋으면 외운 것이다.
