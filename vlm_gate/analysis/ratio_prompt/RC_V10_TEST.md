## 예측 채점 — 4개 중 3개 맞음

| 예측 | 결과 | |

| A 가 접근에서 2.0 아래로 | 3.01 -> **1.10** | 맞음 |

"표현할 수 있나" 를 못 잰다. 점이 다섯이라 rho 가 0.1 단위로 튀기도 한다.
