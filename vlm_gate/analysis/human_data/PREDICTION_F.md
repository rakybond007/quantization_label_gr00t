# 거울 문항(F)을 더하면 내려놓기가 운반 아래로 내려오나 — **돌리기 전 예측**

C(폭 컷)·D(좁힘)는 확정. 이번엔 **문항 하나만 더한다.**

```
F) Is the robot LOWERING what it still holds onto its target right now -- the object
   still in the hand, coming down onto the spot it must end up, not yet let go?
```
부호 **−1**(감점). B 의 거울이다 -- B 가 "지금 집는 중" 이면 F 는 "지금 놓는 중" 이다.

## 왜 문항을 더해야 하는가 (분해로 나온 결론)

운반 -> 내려놓으러 상승분이 거의 전부 D 다.

```
pnp    A −0.016  B −0.009  C −0.027  D +0.060  E +0.005   합 +0.013
long   A  0.000  B  0.000  C +0.027  D +0.073  E  0.000   합 +0.100
```

D 를 좁혀도 내려놓으러에서 1.9~2.1 로 올라온다. **D 는 부호가 +1 이라 "안 올리는 것"
까지가 한계이고 내리지는 못한다.** 그 순간에 켜지면서 부호가 −1 인 문항이 없으면
내려놓으러가 운반 아래로 갈 수 없다.

## 현재 도달점

| | 집으러 | 파지 | 운반 | 내려놓으러 | 물러남 |
|---|---:|---:|---:|---:|---:|
| pnp | 0.541 | 0.543 | 0.724 | **0.731** | 0.827 |
| long | 0.361 | 0.356 | 0.553 | **0.603** | 0.620 |

집기는 목표 달성. 놓기가 미달.

## 예측

- **F 가 4내려놓으러에서 4 이상, 3운반과 5물러남에서 2 이하.** 운반은 아직 목표 위가
  아니고 물러남은 이미 놓았다.
- F 가 1집으러·2파지에서도 낮다(1~2). 그때는 쥔 것이 없다.
- 가중을 아직 안 잡았으므로 잠정으로 위험 쪽에 B 와 같은 몫을 준다. 그러면
  **4내려놓으러가 3운반 아래로 내려온다** -- 두 데이터셋 모두.
- A·B·C·E 는 80% 이상 그대로. 단 D 와는 물릴 수 있다(D 좁힘 때 C 가 71% 로 흔들린
  전례가 있다). D 가 흔들리는 것 자체는 문제가 아니다 -- F 와 D 는 같은 축의 앞뒤다.

## 실패로 볼 조건

- F 가 4내려놓으러에서 3 미만이면 문구가 그 순간을 못 집는 것이다.
- F 가 5물러남에서도 4 이상이면 "아직 안 놓았다" 를 모델이 못 가르는 것이고, 그러면
  D 와 구분이 안 되어 한 축에 문항 둘을 쓰는 셈이 된다.
- 문항이 늘어 다른 문항 답이 크게 바뀌면(allex 에서 5번째 문항 추가 시 AUC 0.842 ->
  0.718) 그것도 비용이다. A·B·C 동일 비율 80% 미만이면 경고로 본다.
