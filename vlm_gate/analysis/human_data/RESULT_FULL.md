# human_data 전량 라벨링 결과 — 역치가 나왔다

Gemini 3.8 Flash(low) · stride 16 (청크 길이와 같아 겹침도 빈틈도 없다) ·
**2,331청크 · 파싱실패 0 · $6.61 · 20.5분.**

문항은 libero 정본에서 셋을 고친 판(C 폭컷 · D 좁힘 · F 거울). 나간 전문은
`FINAL_PROMPT.txt` 이고 라벨러가 직접 쓴 것이다.

## 역치 — 요구한 60~70% 가 나온다

**tau = 0.47** · long 내려놓기 **61%** 차단(압축 안 함) · 운반 **14%** 차단.

표본 600청크에서는 계단 때문에 30% -> 77% 로 건너뛰어 이 칸이 비어 있었다. 전량
1,149청크(국면이 붙은 것)에서는 conf 값이 촘촘해져 61% 가 잡힌다. **표본으로 역치를
추정하지 말고 전량 분포에서 잡아야 한다는 사례다.**

```
tau 0.45   내려놓기 23%   운반  1%
tau 0.47   내려놓기 61%   운반 14%   <- 권고
tau 0.50   내려놓기 77%   운반 42%
tau 0.55   내려놓기 92%   운반 63%
```

- **long**: 내려놓기가 운반 아래(0.480 < 0.527), 집기 두 국면이 최저. 의도한 순서다.

  목적지가 넓은 사발이라 그게 맞다.

국면이 붙은 것은 1,149청크다. 나머지 1,182개는 국면 지점에서 8스텝 넘게 떨어진
청크(에피 시작·끝, 주기 사이)라 국면 라벨이 없다. 라벨 자체는 2,331개 다 있다.

## 아직 안 정한 것

**가중이 잠정이다.** 지금은 libero 가중에 F 를 B 와 같은 몫으로 끼운 값이다. 위 tau 는
그 가중 기준이므로, 가중을 확정하면 conf 값이 옮겨가고 tau 도 다시 잡아야 한다(R5).
