# 표본 600청크 — 국면별 conf 와 역치

문항은 C 폭컷 + D 좁힘 + F 거울. 판정기 Gemini 3.8 Flash(low). $1.66.
국면은 그리퍼 전이에서 찍되 **에피별로 정규화한 문턱**을 쓰고 **모든 잡기-놓기 주기**를
쓴다(앞 판에서 long 은 154주기 중 103개를 버리고 있었다).

## 국면별 conf

| pnp (n=289) | 집으러 | 파지 | 운반 | 내려놓으러 | 물러남 |
|---|---:|---:|---:|---:|---:|
| 평균 | 0.580 | 0.572 | 0.691 | 0.646 | **0.699** |

| long (n=298) | 집으러 | 파지 | 운반 | 내려놓으러 | 물러남 |
|---|---:|---:|---:|---:|---:|
| 평균 | 0.419 | 0.412 | 0.530 | **0.462** | 0.483 |

**pnp 물러남은 문제 없다.** 표본 100개일 때 0.713 으로 낮아 보였던 것은 표본이 얇아서
였고, 289개에서는 운반(0.691)보다 위인 0.699 로 제일 높다.

**long 은 내려놓기가 운반 아래로 내려왔다** (0.462 < 0.530). F 가 한 일이다 --
그 국면에서 F 평균 4.03, 운반에서 1.63. 나머지 문항은 두 국면이 거의 같다
(A 1.0/1.2 · B 1.0/1.2 · C 1.83/1.85 · E 1.0/1.2).

## 역치 — 요구한 60~70% 칸은 비어 있다

```
tau 0.44~0.465   내려놓기  30%   운반   2%    차 28%
tau 0.47~0.50    내려놓기  77%   운반  15%    차 62%   <- 실질 최적
tau 0.505~0.53   내려놓기  93%   운반  33%    차 60%
tau 0.535~       내려놓기 100%   운반  60%    차 40%
```

conf 가 이산이라서다. long 내려놓기 60청크가 가지는 conf 는 여섯 값뿐이고
(0.367×3 · 0.400×2 · 0.433×13 · 0.467×28 · 0.500×10 · 0.533×4) 0.467 과 0.500
사이에는 청크가 하나도 없다. 그래서 차단율이 30% -> 77% -> 93% 로 건너뛴다.

등급 패턴도 몇 개뿐이다 -- 내려놓기는 `112114` 23개 · `112115` 11개 · `112214` 8개다.

**권고: tau = 0.48** (평탄 구간 한가운데). 내려놓기 77% 차단 · 운반 15% 차단.
정확히 0.500 에 놓으면 값 위에 걸터앉아 부등호 방향에 따라 77% 와 93% 가 갈린다.

**이 tau 는 잠정 가중 기준이다.** 가중을 확정하면 conf 값이 옮겨가므로 다시 잡는다.

## 곁가지 확인 — C 는 지시문 단어를 읽는가

C 가 `cup` 을 적는데 long 지시문에도 `red cup` 이 있다. 지시문에서 목적지 단어만
가리고(`red cup` -> `marked spot`) 120청크를 다시 돌렸다.

```
C 평균   pnp  4.28 -> 4.15   long  1.83 -> 1.83
```

**평균이 안 움직인다. 화면을 읽고 있다.** 단어를 보고 답했다면 long 이 위로 튀었어야 한다.

다만 분포는 퍼진다(long `1:11 2:48 3:1` -> `1:25 2:21 3:13 4:1`, 개별 일치 35%).
단어가 평균을 정하지는 않지만 확신을 굳혀 준다. 그리고 **지시문은 전역으로 작용한다** --
한 단어를 바꿨는데 다른 문항이 전부 흔들렸다(A 72% · B 76% · D 68% · E 77% · F 60%).
문항 하나를 바꿀 때 다른 문항이 81~92% 유지되는 것과 대조된다.
