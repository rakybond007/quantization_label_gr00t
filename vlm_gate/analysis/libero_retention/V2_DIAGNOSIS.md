## robocasa 에서 온 문구가 그대로 통했다

| | robocasa | libero |
|---|---|---|
| D "손을 떼는 순간인가" | 해제 1.34 -> **3.51** | 해제 -> **4.61** |
| B "파지 순간인가" | -- | 파지 -> **4.56** |

**같은 문구가 두 벤치마크에서 같은 국면을 살렸다.** 진단 규칙("4등급 이상이 0~5% 면
죽은 문항이고 원인은 부호·가중이 아니라 문구가 화면과 안 맞는 것")도 그대로 옮겨졌다.
문항 설계가 벤치마크마다 처음부터 다시 할 일이 아니라는 뜻이다.

v3c = v3a + v3b (둘 다 재조준) 를 시험 중이다.
