# 배속 결정 — 서브액션 분해 결과 (2026-09-14)

## 방법

태스크를 서브액션으로 쪼개고, 실측 배속 사다리에서 **서브액션별 배속 한계**를
역산한다. 태스크 상한 = 그 태스크가 지나는 서브액션 한계의 **최솟값**(병목 모형).

    A: 잡기 -> 운반 -> 조심히 놓기,  2배까지
    B: 잡기 -> 운반 -> 대충 놓기,    3배까지
    => 잡기·운반은 3배 이상, 조심히 놓기는 2배

이렇게 하면 **안 본 태스크의 상한도 조합으로 나온다.** 측정한 태스크에만 쓸 수
있는 룩업표와 다른 점이 이것이다.

축이 작다.**

### 문항 아홉 판이 다 실패한 이유 -- 하네스 R1 을 안 지켰다

> 주 채점은 국면 지표로 하고 태스크 상관은 부호 확인용으로만 쓴다.

v1a~sa2 를 전부 태스크당 순위상관으로 채점했다. R1 이 예고한 대로 수렴했다 --
sa1 범위 2.2~2.5, sa2 는 69% 가 한 답으로 붕괴.
