# 실험 매트릭스 관리표 (도메인 × 티처 × 아키텍처 × τ)

## 원칙
- **최종 판정은 폐루프 성공률·스텝** (robocasa). 내재적 지표(그리퍼AUC·일관성·qrate)는 스크리닝용.
- **τ(게이트 임계값)는 (티처 × 아키텍처)마다 다른 탐색 대상**. τ=0.5는 임의값이며, judge마다 confidence 캘리브레이션이 달라 같은 0.5가 다른 동작점을 뜻함.
  - 예: cosmos 학생 conf 최대 0.726(qrate@0.5=0.19) vs gemma 학생 최대 0.999(qrate@0.5=0.53)
- τ 탐색은 evolve 루프의 일부로 간주하되, **튜닝 태스크/홀드아웃 태스크 분리** 필수(테스트셋 튜닝 방지).

## 확정된 부정 결과 (재실험 금지)
- **K3 혼합**: 클리핑 해제해도 K2 미달. 단 τ3를 학생별 분포에서 골라야 함(과거 실험은 K3 미발동으로 무효).
- **동역학 보정**: clip 해제 후에도 naive K2와 동일(0.595 vs 0.598) → 성공률 회복은 게이트 몫.
- **reasoning=none 단독**: robocasa 라벨 붕괴(이웃상관 0.058).
- **모션 3프레임 입력**: evolve 루프 배포 불가(단일 프레임 제약) → 폐기.

## cosmos 라벨링 프로토콜 (2026-08-20 확정)
프레임당 **2콜**: 시각 4문항 1콜 + 액션 4문항 1콜. 이미지 프리필 1회 후 답 스캐폴드
`A) YES\nB) NO ...`를 티처포싱하며 각 슬롯에서 `P(YES|{YES,NO})`를 읽는다.

| | 8콜(문항당 프리필) | **2콜(슬롯 채점)** |
|---|---|---|
| 처리량 | 1,450 프레임/시/GPU | **6,015 프레임/시/GPU** |
| 262k 전량 | 180 GPU-시 | **43.6 GPU-시** (16샤드 ≈ 2.7시간) |
| AUC(층화 1,295) | 0.763 | **0.830** (ΔAUC +0.066, 95% CI [+0.023,+0.107]) |
| 차단 35% 검출/정밀도 | 70.5% / 13.7% | **81.8% / 15.9%** |

실패한 1차 시도(기록): 라벨 없는 4글자 `YNNY` + 단일문자 Y/N 토큰 채점 → 전 프레임
동일 답, 종합 r=0.52로 붕괴. 슬롯 라벨 앵커와 YES/NO 단어 토큰 두 가지가 모두 필요.
