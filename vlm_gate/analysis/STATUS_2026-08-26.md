OpenDrawer에서 82% 압축하고도 0.68 — naive K2(0.44)와 명확히 다르다.
cycle5의 과거 결과(0.70/82%)가 독립 재현됨.
=> **어디를 압축하느냐가 얼마나 압축하느냐보다 중요하다**는 직접 증거.

### 방법론에서 확정된 것
- 2회 분리 호출 > 1회 8문항 (AUC 0.830 vs 0.763), 슬롯 채점으로 3.6배 빠름
- 액션 문항은 VLM이 못 읽음 (방향 반전 AUC 0.520) → 계산으로 내려야 함
- 계산값은 "질문"이 아니라 "사실"로 진술해야 함 (묻으면 모델이 사실을 복창)
- 가이던스만 국면 기준으로 바꾸면 효과 없음 — **문항도 국면 기준이어야** 함
- 프롬프트 어휘는 관측 가능한 동작으로만. 은유·정도부사 금지
