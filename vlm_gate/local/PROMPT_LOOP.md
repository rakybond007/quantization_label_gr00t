# 문항을 고쳐 나가는 루프의 명세

`PROMPT_METHOD.md` 는 **무엇이 좋은 문항인가**를 적는다. 이 문서는 **그것을
어떻게 반복해서 얻는가**를 적는다. 둘을 나누는 이유는, 명세가 없으면 검증에
걸린 쪽을 고치는 대신 검증을 고치게 되기 때문이다. 실제로 2026-09-04 에
검증 5번이 안 맞자 5번의 기대치를 완화하려는 판단이 나왔다. 그것을 막는 것이
이 문서의 목적이다.

## 루프에 들어가기 전에 얼어붙는 것

t=0 이전에 정하고, 루프가 끝날 때까지 **한 글자도 못 바꾼다.**

| 기호 | 무엇 | 왜 얼리나 |
|---|---|---|
| **E** 손상표 | 측정된 (행동, 물체) → 배속. allex 는 4칸 | 문항이 맞춰야 할 대상. 이게 움직이면 아무것도 반증되지 않는다 |
| **S** 명세 | `PROMPT_METHOD.md` 의 "문항이 갖춰야 할 것" | 수정의 정당성이 나오는 곳 |
| **A** 수용 술어 | 검증 5항목과 **숫자로 적힌** 임계값 | 사후에 정하면 언제나 통과한다 |
| **D** 개발집합 | 층화표본, 셀당 n (아래) | 크기를 그때그때 정하면 검정력이 문항마다 달라진다 |
| **H** 보류집합 | D 와 겹치지 않는 같은 층화표본 | 한 번만 쓴다 |
| **K** 예산 | 반복 횟수 상한 | 소진되면 실패로 보고한다. 임계값을 낮추지 않는다 |

## D 와 H 의 크기는 계산해서 정한다

지금까지는 "에피소드 0~3" 이었다. 그건 편해서 고른 것이지 근거가 아니고,
실제로 검정력이 셀마다 6배 차이났다 — Rotate PolyBag 41청크, Rotate Box
308청크. **41개로 부호 차 0.3 을 판정할 수 없다.**

두 통계량이 크기를 정한다.

**검증 2 (최빈답 비율).** 임계 0.90 근처에서 ±0.03 을 보려면
n ≥ p(1-p)·1.96²/0.03² = 0.9·0.1·4269 ≈ **384**.

**검증 3 (부호 차).** 1~5 등급의 표준편차를 1.2 로 두고 Δ=0.3 을 α=0.05,
검정력 0.8 로 잡으려면 셀당
n ≥ 2σ²(z+z)²/Δ² = 2·1.44·7.85/0.09 ≈ **251**.

셀당 251 이 더 크고 셀은 넷이므로 **D 는 셀당 250, 합 1000 청크**다.
H 도 같은 방식으로 셀당 250. 층은 E 의 칸, 즉 (옮김·뒤집음) × (단단함·무너짐)
이고 **주석에서 층을 읽되 모델에는 주지 않는다.** 셀이 모자라면 그 셀의
부호 판정은 "검정력 부족" 으로 보고하고 통과로 세지 않는다.

## 한 바퀴

    상태 t = (문항집합 Qt, 등급표 Lt, 산술 ft)

    1. 라벨    D 를 Qt·Lt 로 라벨링한다. 배치 폭과 샤드를 meta 에 남긴다.
    2. 측정    A 의 5항목을 전부 계산한다. 하나가 떨어져도 나머지를 다 잰다 --
               어디가 무너졌는지가 다음 수정의 근거이기 때문이다.
    3. 판정    A 가 전부 통과하면 5 로. 아니면 4 로.
    4. 수정    떨어진 항목 하나를 지목하고, S 의 어느 조항을 어겼는지 쓰고,
               그 조항에 맞게 고친다. t += 1, 1 로 돌아간다.
    5. 확인    H 에 한 번 돌린다. 통과하면 끝. 떨어지면 D 에 과적합된 것이며,
               **H 로는 다시 고치지 않는다.** 그 사실을 보고하고 D 를 새로
               뽑아 t=0 부터 다시 시작한다.

## 수정에 붙는 규칙

- **R1 임계값과 E 는 루프 안에서 못 바꾼다.** 검증이 안 맞으면 문항이 틀린
  것이지 검증이 틀린 게 아니다.
- **R2 모든 수정은 떨어진 항목 하나를 지목해야 한다.** 어느 항목도 지목하지
  못하는 수정은 취향이지 수렴이 아니다.
- **R3 한 바퀴에 한 축만 고친다.** 문항 나눔 / 문항 서술 / 등급표 서술 셋 중
  하나. 셋을 같이 고치면 무엇이 들었는지 알 수 없다.
- **R4 H 는 한 번만 쓴다.**
- **R5 예산 K 를 넘기면 실패로 보고한다.**

## 남는 기록

한 바퀴마다 한 줄:

    t | 문항집합 해시 | 5항목 수치 | 떨어진 항목 | 어긴 조항 | 고친 축 | 무엇을

이 표가 결과물이다. 통과한 문항집합만 남기면 어떤 수정이 무엇을 고쳤는지
알 수 없고, 다음 벤치마크에서 같은 자리를 다시 밟는다.

## 지금까지의 기록 (allex, D = 에피소드 0~3 → 명세 위반, 층화 아님)

| t | 5항목 | 떨어진 항목 | 어긴 조항 | 고친 축 |
|---|---|---|---|---|
| 0 | 형식 100%, 최빈 A99 C95 D100 E99 | 2 | 중간 등급이 도피처 / 항상 참인 문항 / 아는 것을 되물음 | 나눔 5→3 |
| 1 | 형식 100%, 최빈 93/90/91, 부호 −0.03/−0.07/+0.11 | 2, 3 | 스틸에서 답할 수 없는 것을 물음(움직임) | 미정 |

t=1 의 원인은 하나로 모인다: **모델은 정지 화면을 본다.** "옮겨지고 있는가",
"돌아가고 있는가" 는 한 장에서 답할 수 없고, 움직임은 이미 `arm_speed`,
`translation`, `wrist_rot` 로 계산돼 사실로 나간다. S 의 "화면에서 판정된다"
와 "계산으로 안 나오는 것이어야 한다" 를 동시에 어겼다.
