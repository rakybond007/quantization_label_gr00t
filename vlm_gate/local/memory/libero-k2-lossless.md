# LIBERO 는 K2 전면 압축에서 손실이 없다 (2026-09-03 측정)

40태스크 × 50에피소드, 다른 연구자(taekwan)의 `_restored` 결과를 우리 무압축
기준선과 대조:

```
무압축        1857/2000  92.9%
K2 전면 압축   1860/2000  93.0%
K2 경계보호    1907/2000  95.4%
K4 경계보호    1348/2000  67.4%
```

**태스크별 K2 손상으로 문항을 뽑으면 안 된다.** ±0.14~0.22 로 보이던 것이 전부
표본 오차다(50에피소드면 1 표준오차가 0.03~0.04). 실제로 K2 손상과 K4 손상의
상관은 0.072 로 무관하다. K4 를 써야 신호가 있다.

## 위험은 그리퍼 전환 순간에 몰려 있다

`K2 전면` 과 `K2 경계보호` 는 그리퍼 전환 청크(전체의 2~5%)를 압축하느냐만
다르다. baseline 성공 에피소드를 짝지어 세면:

```
경계보호 성공 & 전면압축 실패   128
전면압축 성공 & 경계보호 실패    52     순 +76 (p~1e-8)
```

나머지 95% 를 다 압축해도 손실이 없는데 그 2~5% 만 보호하면 이만큼 회복된다.

## K4 가 깨뜨리는 것은 파지다

```
              1회 시도 파지 성공   끝까지 파지 못함
K2 경계보호        89.9%            3.9%
K4 경계보호        65.2%           17.4%
```

K4 실패 581건: 파지 실패 46.6% / 들고 가다 놓침 16.9% / 못 들고 접촉 상실 23.1%
/ 쥐고도 태스크 실패 13.4%. **놓기(배치)가 압축에 취약하다는 직접 증거는 없다.**

기전: 팔의 델타는 스텝 상한에 걸려 못 따라가는데 그리퍼 비트는 계획 스케줄대로
그냥 뒤집힌다. K4 는 K2 보다 중앙값 7 env step 먼저 닫고(80.5% 에피소드에서),
그때 팔은 목표에서 벗어나 있다:

```
닫는 순간 수평 오프셋   파지 성공 2.3cm   실패 4.3cm   AUC 0.726
5cm 초과 → 1회 파지 실패율 68% (평균 37%)
```

이건 게이트가 아니라 압축 구현으로 고칠 수 있는 문제일 수 있다 — 그리퍼 전환을
팔이 도착할 때까지 미루는 것. 게이트와 별개로 검토할 것.

## 이송 구간은 안전하다

그리퍼 전환에서 ±9 step 이상 떨어진 청크가 76.3%. 이송 중 압축이 만든 편차는
중앙값 13cm 인데 성공/실패를 전혀 안 가른다(AUC 0.539) — 재계획이 되돌린다.
[[harness-limits-not-labels]] 의 클리핑과 같은 결론이 여기서도 나온다:
clip_frac / clip_excess 의 판별력 AUC 0.39~0.53 으로 무의미.

## 문항에 주는 함의

액션 파생 12개 피처로 "이 폐쇄가 물체를 잡을지" 를 예측한 AUC 는 0.39~0.60 으로
우연 수준이다. 성공을 가르는 유일한 강한 변수(수평 오프셋)는 참조 궤적이 있어야
계산되므로 온라인에서는 **이미지로만 안다.** 그러므로 문항은

  "지금 이 프레임에서 그리퍼가 대상 물체를 물 수 있는 위치에 와 있는가"

형태여야 한다. 부수 후보로 "물체의 파지 폭 여유" — 성공한 파지의 개구는 물체
두께(0.042), 실패는 0.003(허공)이라 얇은 물체는 오차를 흡수할 여유가 없다.
