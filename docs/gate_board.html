Fixed today

Four failures, each invisible in what was being watched

The gate never trained

Every N1.7 joint run left the gate head at its initialization — parameters moved by exactly 0 across 4,000 steps while the backbone moved 3–7e-3. The label join read the episode index off a DataFrame that never carries it, so every sample counted as unlabelled and the loss was exactly zero.

The smoke tested the part, not the wiring

It attached the gate, ran the backbone, applied BCE to the head and checked gradients arrived. It never called the model's forward, which is where the label had to travel from the dataset to the loss — the path that was broken.

Hyperparameters never reached python

Comment lines sat between backslash-continued arguments, so the joined line commented out everything after --output-dir. --max-steps and --global-batch-size were silently dropped and every run used config defaults. A job named 60k trained 10,000 steps.

Training on the superseded variant

The joint run used the binary aggregation, where 29.51% of chunks collapse to zero and take arbitrary ranks. A frozen student can ignore that block; here the gradient flows through the four backbone layers the action head shares.
